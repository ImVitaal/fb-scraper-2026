# Security

## Sensitive data

Keep session material and private raw captures outside this repository.

The application must never store account passwords.

Use only redacted, synthetic fixtures in commits and tests.

## Reports

Report security defects privately to the repository owner.

Include the affected version, reproduction steps, and expected impact.

Do not include session material or private Group content.

## Supported version

Phase 1 supports only the current `main` branch.
