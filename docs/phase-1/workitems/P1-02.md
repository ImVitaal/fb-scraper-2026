## Scope

Define the versioned Group, Post, Comment, evidence, state, and observation
contracts. Add ordered SQLite migrations and repositories for durable canonical
records, observations, and job-state transitions.

## Exclusions

- Raw capture byte storage and retention.
- Session secret encryption.
- Source parsing.
- Browser or network adapters.
- CLI behavior beyond the existing skeleton.

## Completion

implemented. SQLite migration 001 creates every required persistence category.

and valid job transitions.

installed wheel. Repository and packaged SQL copies are byte-equal.
